Architecture — before and after

Same HTTP surfaces. The change is that credential acceptance becomes an explicit CombinationID resolved once, then checked against the route table — not implicit middleware that silently ignores the wrong credential family.

Before

Each door had its own middleware. A key on a session route was ignored, not refused.

After (ADR-0118 / #422)

Order fixed: resolve (401) → route lists combination (401) → guard (403) → reach (404).
